Bloco 1 · Aulas 1 e 2 · 25 min

O programa conversa com você

O que é algoritmo, o esqueleto de um programa no VisuAlg, variáveis, e os comandos para mostrar coisas na tela e ler o que a pessoa digita.

Algoritmo é uma receita

Algoritmo é uma lista de passos, em ordem, para resolver um problema. Igual a uma receita de bolo: tem os ingredientes, o modo de preparo e o bolo pronto. Todo programa da N1 segue o mesmo caminho:

Entrada

O que o programa recebe. No VisuAlg: leia.

→

Processamento

As contas e as decisões. No VisuAlg: <-, se, laços.

→

Saída

O que o programa mostra. No VisuAlg: escreval.

Exemplo, média de duas notas: a entrada são as duas notas, o processamento é somar e dividir por 2, a saída é mostrar a média.

Portugol é esse jeito de escrever algoritmo em português. O VisuAlg é o programa que entende Portugol e executa. Esta página tem um simulador do VisuAlg, então tudo roda aqui no navegador.

O esqueleto de todo programa

Todo programa no VisuAlg tem estas partes, sempre nesta ordem. Aperte Executar:

algoritmo "ola"O nome do programa, entre aspas.
varAqui você cria as variáveis (as caixinhas). Pode ficar vazio.
inicioDaqui para baixo vêm os comandos. O computador executa de cima para baixo, uma linha por vez.
// textoComentário. O computador ignora; serve para você anotar.
fimalgoritmoFim do programa.

Dica

Para o VisuAlg, Escreval, ESCREVAL e escreval são a mesma coisa. Mas escreva as palavras do VisuAlg sem acento: entao, senao, faca, ate, logico. Acento só dentro de texto entre aspas.

Variável é uma caixinha

Variável é um espaço na memória do computador que tem nome. Pense numa caixinha com etiqueta: o nome é a etiqueta, o tipo diz o que cabe dentro e o valor é o que está lá agora.

Uma variável guarda um valor por vez. Guardou outro, o anterior some.

TipoGuardaExemplos
inteironúmero sem vírgula10 -3 0 2026
realnúmero com vírgula (no código, use ponto)7.5 3.14 -0.5
caracteretexto, sempre entre aspas"Ana" "SP" "123"
logicosó VERDADEIRO ou FALSOVERDADEIRO

As variáveis são criadas (declaradas) na seção var: nome, dois-pontos, tipo. Várias do mesmo tipo vão separadas por vírgula.

var
   idade: inteiro
   altura, peso: real
   nome: caractere
   aprovado: logico

Regras para o nome:

  • começa com letra: nota1 certo, 1nota errado
  • sem espaço: nota_final ou notaFinal certo, nota final errado
  • sem acento e sem símbolos: media certo, média e valor$ errado
  • não pode ser palavra do VisuAlg: se, para, inicio... errado
Pegadinha de prova

"123" com aspas é texto. 123 sem aspas é número. Com números, 5 + 5 dá 10. Com textos, "5" + "5" junta e dá "55".

Guardar um valor: <- (lê-se "recebe")

A seta aponta para onde o valor vai: x <- 5 guarda 5 em x.

x <- x + 1 parece estranho, mas se lê assim: pegue o valor de x (5), some 1 e guarde de volta em x. O lado direito é calculado primeiro; depois o resultado vai para a caixinha da esquerda. Essa linha vai aparecer muito nos laços do bloco 5.

Mostrar na tela: escreva e escreval

  • escreva mostra e continua na mesma linha. escreval mostra e pula para a linha de baixo (o L é de linha).
  • A vírgula junta pedaços: escreval("Idade:", idade).
  • Texto entre aspas aparece igualzinho. Variável sem aspas mostra o valor. Conta mostra o resultado.

Dica

O VisuAlg coloca sozinho um espaço antes de cada número. Por isso escrevemos "Idade:" sem espaço no fim. Com texto ele não faz isso: escreval("Oi, ", nome) precisa do espaço depois da vírgula.

Ler do teclado: leia

leia(variavel) faz o programa parar e esperar a pessoa digitar e apertar Enter. O que ela digitar vai para a variável. Sempre mostre uma mensagem antes do leia, senão a pessoa não sabe o que digitar.

Números com vírgula e formatação

No código, número com vírgula se escreve com ponto: 7.5. Para mostrar com um número certo de casas, use variavel:tamanho:casas. Exemplo: media:6:2 usa 6 espaços e 2 casas depois do ponto.

Os dois mostram na tela. O escreval pula linha no final; o escreva continua na mesma linha.

Contas e precedência

Os operadores de conta e de comparação, e a ordem em que o computador resolve uma expressão. Cai muito em prova.

Os operadores de conta

OperadorO que fazExemploResultado
+soma7 + 29
-subtração7 - 25
*multiplicação7 * 214
/divisão (o resultado é sempre real)7 / 23.5
\divisão inteira (só a parte inteira)7 \ 23
mod ou %resto da divisão7 mod 21
^potência2 ^ 38

Divisão inteira e resto: a conta armada da escola

Lembra da conta de dividir armada? 17 dividido por 5: o 5 cabe 3 vezes no 17 (5 × 3 = 15) e sobram 2.

   17 |_5___
  -15   3     ← 17 \ 5 = 3     (quantas vezes cabe)
  ---
    2         ← 17 mod 5 = 2   (o que sobra)

Para que serve o resto na prática:

  • Par ou ímpar: n mod 2 = 0 quer dizer par (dividindo por 2 não sobra nada).
  • Divisível por 3: n mod 3 = 0.
  • Último dígito: n mod 10 (de 472 sobra 2).
  • Tirar o último dígito: n \ 10 (472 vira 47).

Precedência: quem vai primeiro

Quando há várias operações juntas, o computador não vai simplesmente da esquerda para a direita. Ele segue esta ordem:

  1. ( ) parênteses
  2. ^ potência
  3. * / \ mod (entre eles, da esquerda para a direita)
  4. + - (entre eles, da esquerda para a direita)
  5. comparações: = <> > < >= <=
  6. nao
  7. e
  8. ou

É a mesma ordem da matemática da escola. Na dúvida, coloque parênteses: eles nunca atrapalham.

Digite qualquer conta e veja a ordem de resolução, passo a passo. Use para conferir as questões de "resolva a expressão":

Pegadinha de prova: a média sem parênteses

n1 + n2 / 2 divide só o n2! Com notas 8 e 6 dá 8 + 3 = 11. O certo é (n1 + n2) / 2, que dá 7.

Comparações: a resposta é VERDADEIRO ou FALSO

SinalSignificaExemplo
=igual3 = 3 dá VERDADEIRO
<>diferente3 <> 4 dá VERDADEIRO
>maior que7 > 7 dá FALSO
<menor que2 < 9 dá VERDADEIRO
>=maior ou igual7 >= 7 dá VERDADEIRO
<=menor ou igual8 <= 5 dá FALSO
Pegadinha de prova

= só compara. Para guardar é <-. Diferente é <> (não existe != nem == no VisuAlg). E é >=, com o sinal de maior primeiro.

Funções prontas (bônus)

raizq(16) dá 4 (raiz quadrada) · abs(-7) dá 7 (valor sem sinal) · int(7.9) dá 7 (só a parte inteira) · x ^ 2 é x ao quadrado.

Quanto vale 2 + 3 * 4?

  1. 20
  2. 14
  3. 24
  4. 9
Multiplicação primeiro: 3 * 4 = 12. Depois 2 + 12 = 14.

Quanto vale 17 mod 5?

  1. 3
  2. 2
  3. 3.4
  4. 85
17 dividido por 5 dá 3 e sobram 2. O mod é o que sobra.

Quanto vale 17 \ 5?

  1. 3
  2. 2
  3. 3.4
  4. 12
Divisão inteira: quantas vezes o 5 cabe no 17, que é 3. O que vem depois da vírgula é jogado fora.

Quanto vale (8 + 4) / 2 ^ 2?

  1. 36
  2. 3
  3. 6
  4. 10
Parênteses: 8 + 4 = 12. Potência: 2 ^ 2 = 4. Divisão: 12 / 4 = 3.

Quanto vale 10 - 2 * 3 + 1?

  1. 3
  2. 5
  3. 25
  4. 4
2 * 3 = 6. Depois, da esquerda para a direita: 10 - 6 = 4 e 4 + 1 = 5. Quem faz 6 + 1 antes chega em 3, que está errado.

  1. a + b / 2
  2. (a + b) / 2
  3. a + (b / 2)
  4. (a + b / 2)
Sem os parênteses em volta da soma, só o b é dividido por 2.

Bloco 3 · Aula 4 · 40 min

O programa toma decisões

Comparações dentro do se, o senao, o se aninhado e o comando escolha.

Até agora o programa fazia sempre a mesma coisa. Com o se ele decide: olha uma condição (uma pergunta cuja resposta é VERDADEIRO ou FALSO) e escolhe o caminho.

se ... entao ... fimse

Leia em voz alta: "se a idade for maior ou igual a 18, então mostre a frase; fim do se". Se a condição der FALSO, o programa pula tudo até o fimse e continua dali.

se ... senao: um caminho ou o outro

Com senao, roda exatamente um dos dois blocos. Nunca os dois, nunca nenhum.

Dica: indente

Empurre para a direita (3 espaços) o que está dentro do se. O VisuAlg não obriga, mas fica muito mais fácil ver onde cada bloco começa e termina. Aqui no editor, a tecla Tab coloca os 3 espaços.

O clássico par ou ímpar usa o resto da divisão por 2:

se aninhado: mais de dois caminhos

Quando existem três ou mais respostas possíveis, coloca-se um se dentro do senao de outro.

Raciocínio: se chegou no senao do primeiro se, já sabemos que a média é menor que 7. Lá dentro, outro se separa recuperação de reprovado.

Pegadinha de prova

Conte: 2 se, 2 fimse. Cada se tem o seu fimse, inclusive o que está dentro do senao.

A ordem das perguntas importa. Teste da maior nota para a menor. Se perguntar primeiro media >= 4, quem tirou 9 cai em Recuperação, porque 9 também é maior que 4.

escolha: vários valores exatos

Quando a mesma variável é comparada com vários valores certinhos (1, 2, 3...), o escolha fica mais limpo que um monte de se.

  • O escolha olha o valor da variável e pula direto para o caso igual.
  • outrocaso é o "nenhum dos anteriores" (igual ao último senao). É opcional.
  • Um caso pode ter vários valores: caso 6, 7.
  • Funciona com texto também, entre aspas: caso "+".
Pegadinha de prova

O escolha só testa igualdade. Para faixas, como nota >= 7, use se.

Use se quando...Use escolha quando...
compara faixas (>, <, >=)compara a mesma variável com valores exatos
junta condições com e / oué um menu de opções (1, 2, 3...)

Bloco 4 · Aula 5 · 25 min

Juntando condições: e, ou, nao

Condições compostas, a tabela-verdade e como resolver expressões lógicas na prova.

Quando uma pergunta só não basta

Para andar na montanha-russa precisa ter 12 anos ou mais e pelo menos 1,40 m. São duas perguntas, e as duas precisam dar VERDADEIRO. Para juntar perguntas existem três palavras:

  • e é exigente: só dá VERDADEIRO se as duas forem VERDADEIRO.
  • ou é bonzinho: basta uma ser VERDADEIRO.
  • nao é do contra: inverte. VERDADEIRO vira FALSO e FALSO vira VERDADEIRO.

Clique em A e em B para trocar os valores e veja os resultados:

A e B
A ou B
nao A
A xou B
ABA e BA ou Bnao A
VVVVF
VFFVF
FVFVV
FFFFV

V = VERDADEIRO, F = FALSO. Bônus: xou dá VERDADEIRO quando os dois lados são diferentes.

Como escrever no VisuAlg

Coloque cada comparação entre parênteses e repita a variável em cada uma.

Pegadinhas de prova
  1. se idade >= 18 e <= 65 entao errado. Repita a variável: se (idade >= 18) e (idade <= 65) entao certo.
  2. se x = 1 ou 2 entao errado. O certo é se (x = 1) ou (x = 2) entao.
  3. Dentro de uma faixa usa e: (x >= 1) e (x <= 10). Fora da faixa usa ou: (x < 1) ou (x > 10).
  4. O e vem antes do ou: VERDADEIRO ou FALSO e FALSO dá VERDADEIRO, porque resolve FALSO e FALSO primeiro. Na dúvida, parênteses.

Com idade = 70, quanto dá (idade >= 18) e (idade <= 65)?

Qual condição testa se x está entre 1 e 10, incluindo o 1 e o 10?

  1. x >= 1 e <= 10
  2. (x >= 1) ou (x <= 10)
  3. (x >= 1) e (x <= 10)
  4. (x > 1) e (x < 10)
A primeira não repete a variável (erro). A segunda, com ou, dá VERDADEIRO para qualquer número. A quarta deixa o 1 e o 10 de fora.

Quanto dá VERDADEIRO ou FALSO e FALSO?

  1. VERDADEIRO
  2. FALSO
O e vem antes: FALSO e FALSO = FALSO. Depois VERDADEIRO ou FALSO = VERDADEIRO. Quem resolve da esquerda para a direita erra essa.

Quanto dá nao (5 > 3)?

  1. VERDADEIRO
  2. FALSO
5 > 3 é VERDADEIRO, e o nao inverte: FALSO.

Bloco 5 · Aula 6 · 50 min

Repetição: o programa aprende a repetir

enquanto, repita ... ate e para. Contador, acumulador e os padrões que mais caem.

Mostrar os números de 1 a 1000 com escreval daria 1000 linhas. Um laço (ou loop) repete um bloco de comandos quantas vezes for preciso. Duas ideias aparecem em quase todo laço:

  • Contador conta quantas vezes algo aconteceu: cont <- cont + 1
  • Acumulador vai somando valores: soma <- soma + num (começa em 0)

Todo laço tem 3 partes: onde começa, até quando vai, e o que muda a cada volta. Esquecer a terceira dá loop infinito.

enquanto ... faca ... fimenquanto

"Enquanto a condição for VERDADEIRO, repete." Ele testa a condição antes de cada volta.

O teste de mesa é fazer no papel o que o computador faz. É assim que se resolve "o que aparece na tela?" na prova:

Voltacontcont <= 5?Mostra
1ª1VERDADEIRO1
2ª2VERDADEIRO2
3ª3VERDADEIRO3
4ª4VERDADEIRO4
5ª5VERDADEIRO5
fim6FALSOsai do laço

Se a condição já começar FALSO, o enquanto não roda nenhuma vez.

Pegadinha de prova: loop infinito

Sem a linha cont <- cont + 1, o cont fica 1 para sempre, a condição nunca fica FALSO e o programa não termina. Apague essa linha no exemplo acima e execute: o simulador para sozinho e avisa (o VisuAlg de verdade fica travado).

repita ... ate

"Repete até a condição ficar VERDADEIRO." Ele testa no fim de cada volta.

A pegadinha mais cobrada do bloco

O enquanto continua quando a condição é VERDADEIRO. O repita para quando a condição é VERDADEIRO. Por isso as condições são opostas: enquanto cont <= 5 faz o mesmo que ate cont > 5.

E o repita sempre roda pelo menos uma vez, porque só testa no fim.

Por rodar pelo menos uma vez, o repita é perfeito para pedir de novo até a pessoa digitar certo:

para ... de ... ate ... faca

Use quando você sabe quantas vezes vai repetir.

O para faz as 3 partes sozinho: começa o i em 1, testa se ele passou de 5 e soma 1 no i no fim de cada volta. Não escreva i <- i + 1 dentro do para. Com passo dá para pular de 2 em 2 ou contar para trás:

A variável do para tem que ser inteiro. Para contar para trás, o passo é negativo: passo -1.
